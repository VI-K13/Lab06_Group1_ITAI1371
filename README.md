## Lab Overview
In this lab, our group worked with the Titanic dataset to explore Linear Regression and Logistic Regression. We used Linear Regression to predict passenger fares based on Age and Pclass, and Logistic Regression to predict passenger survival using Age, Pclass, and Sex. We trained both models, made predictions, and evaluated their performance using different metrics.

## Results
- **Linear Regression:** MSE = 3364.92, RMSE = 58.01
- **Logistic Regression:** Accuracy = 74.83%
